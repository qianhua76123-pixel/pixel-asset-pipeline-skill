# V21 离线 Web 小样

双击 `index.html`。311张部件/装备/材质索引由 `bundle-data.js` 提供，运行不依赖V19/V20目录或服务器。

四种五官方案各有睁眼/闭眼，默认原版；五套衣装含原3套和2套可选精修。支持发肤与衣料分区染色、同钟骨骼动作、装备挂点检查。headStyle随搭配保存，新键为 `nancun-paperdoll-refined-v21-look`；挂点键为 `nancun-paperdoll-refined-v21-offsets`。

头部方案只换head纹理，前辫、身体与骨点保持。精修衣装仅4个新片替换，其余共享。切换微调装备会清除旧状态文案；双手目标移动与单手局部偏移仍分别说明。

完整来源、交叉验证和限制见上级README/qa。未加入V16步态、新美术生成或战斗系统。

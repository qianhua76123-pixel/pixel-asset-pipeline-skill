## 原砚生双眼的具体原因

原眼睛都在 y30–32，同为3×3，左x28–30、右x34–36，没有独立高低错位。原左眼(28,31)为[145,129,120]、(30,31)为[109,87,72]，右对应为[212,206,202]与[248,240,230]；因此左眼显灰暗、右眼白亮，结构重量不一致。`qa/yansheng-eyes-audit.json/png`保留原RGBA证据。此前恢复被去底误删的右眼白只解决了孔洞，不能自动保证两眼画法一致。

本轮三套眼睛分别取V81 A/B/C真实右眼中的眼线、虹膜和眼白，去除明确的邻接肤点，再把同一眼形平移到左/右共同锚点[28,30]/[34,30]。不镜像，所以两眼的高光与明暗方向一致。整对RGBA与alpha形状完全相同，9组实际发型合成后，所有不透明眼睛材质像素也保持此规则；透明角落显示的是连续脸部皮肤，不纳入眼材质等色比较。此为明确的源支持原生构造，不声称是原稿原样双眼。眼睛与眉独立PNG不参与肤/发染色。

## 完整脸底和真实遮挡

使用用户自己的Pixel Studio3410 / JBBT GPT Image2，新生成**1次**完整无发、无眼眉的脸底，包含从前被刘海遮住的完整头皮、额头、脸、耳和短颈。不是挖掉旧发形成透明洞，也不是矩形填肤。原高分图、工作流请求、成功job及画布结果保留在 `runs/complete-face-base-v1`。本子任务允许最多2次AI，本轮只用1次，无重投unknown。

冻结1024原图直接采用生产source-center N40、phase0、deferPalette，经真实Studio/process保存。完整采样头只做整数[12,8]配准，得到x23..40/y19..38的真实完整脸底；发型仍沿原y15头顶，身体/脚底与44高不变。`qa/face-donors.json`逐点核对256个像素到冻结原图，RGB精确相等；没有从旧native放大或重画表面。

脸底在y35以下无损拆分：faceBase到y35，neckSkin为y36–38。二者重组逐RGBA等完整脸底。neckSkin在layer25（torso衣领之前），face在80，eyes82，brows83，前发85，后发75；全部使用同一个整数head变换。衣领可以真实遮住下颈，高领不会被统一脸底强行盖成露颈。

三发型复用V81原源支持的hair语义PNG，同坐标分前/后；后发只包含实际低髻/侧后发，刘海在眼眉前。每发型两片重组逐RGBA等原hair语义片，未新增程序发丝。前/后片的发色索引同步继承；脸/颈有独立肤色索引，眼眉口鼻与轮廓按明确保护mask保留。

三套成对眼睛和平眉都通过Studio原生pixels编辑保存了父子资产，回读RGBA与审稿完全一致；详见 `qa/studio-native-edits` 与包内studioEdits。编辑前母体是各自冻结V81头片；大量alpha删除用于隔离图层，新增双眼像素均为记录中的真实源眼像素复制，不是新画颜色。

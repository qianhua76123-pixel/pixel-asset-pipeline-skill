# 南乡 V82 · 头发、眼睛、体型独立组合

本版针对砚生左右眼不一致以及整头绑定的问题，改成共用完整脸底、独立成对眼睛、独立前后发和两个身体模板。三个选择互不绑定，配六套衣服共108种组合，仍是44px正面小样。

## 直接使用

[本机预览](http://127.0.0.1:3450/)。下载包可双击 `启动自由组合.command`，再在浏览器打开该地址；需要本机已有Python3。如果本机预览服务已在运行，直接打开地址即可。页面自含PNG与脚本，不会发起生图请求。上一版V81与既有四向预览保留在包内入口。

发型、眼型、体型分别选择，随后搭配衣装、发色、肤色和衣色。可以选择站立/正面行走、播放暂停、逐个看8个关键姿势、切村院与近看倍率、显示骨骼、只看独立衣装，或打开“查看分层”。换任意外观保持当前动作进度。

- 发型：清爽短发、侧分低髻、齐耳短发。
- 眼型：明晰圆眼、沉静细眼、柔亮圆眼；左右眼作为一套选择。
- 体型：标准、宽实。宽实的肩宽9.5→11.5px、胯宽6→8px；头、眼睛、身高不拉伸。
- 衣装：沿用V81六套日常衣装，包括围裙、薄袄及素色交领裙装。

## 为什么原来的眼睛不同

V81砚生两眼都约3×3，位于同样的y30–32，但左眼白采到了灰褐色，右眼白更亮。原有整头素材与采样保留了这一差异。此前恢复误去底的右眼白、通过遮罩保护检查，并不等于左右眼的形状与亮暗已经一致。

`presentation/eyes-before-after.png` 是严格同坐标诊断：只把原右眼3×3平移为左眼，改变9个像素，其他头部和身体像素不动；通过用户自己的Studio原生像素编辑保存。它是问题对照，不覆盖V81旧版。

正式模块的三个眼型均从对应已保存来源抽取单眼，作为双眼同向平移的配对资产。两侧的眼线、尺寸、眼白与瞳孔RGB一致，高光方向相同。换发型、皮肤或体型时，不再生成或拉伸眼睛。刘海对眉部的遮挡仍按照真实前发层发生。

## 真正的分层

头部共有12张主PNG：完整脸底1、颈肤1、成对眼睛3、前发/后发共6、平眉1。文件在 `head/assets/v82/head/`，导入合同在 `head/package/head-modules.json`。

脸底和颈肤来自1次项目自有 Pixel Studio/JBBT GPT Image 2 生图，用于补齐原先被头发遮住的表面；没有用矩形肤色涂块代替缺面。发型复用V81的真实来源，眼眉通过Studio原生编辑保存为可追溯子版本。脸和颈分片后合成逐RGBA等于完整来源。颈肤在衣身之前绘制，所以高领能遮住下颈，开领按衣片露肤。

头发、脸底、双眼、眉毛和颈肤共用同一个整数头部变换，走路时不会各自漂动。当前平眉已是独立PNG，但界面固定使用这一款；鼻与嘴仍在共同脸底中，并非所有五官都已开放编辑。

体型合同在 `body/package/body-profiles.json`：宽实档改变左右肩臂链与胯腿链落点，并对衣身、袖裤和刚性裙分别适配宽度。原PNG、sourceBone与遮罩保持，手鞋自身不缩放；这是两种离散模板，尚不是任意比例滑杆。六套衣装使用同一S12动作时钟和8个关键姿势。

## 效果与验证

- `presentation/nine-modular-combinations.png`：三发型×三眼型，固定同一体型和衣装。
- `presentation/two-body-profiles.png`：同头标准/宽实的4×与1×对比。
- `presentation/independent-head-layers.png`：以低髻为例，显示实际独立PNG。
- `presentation/browser-final-modular.png`：实际浏览器选择与角色效果。
- `presentation/modular-shared-walk.png`：无损APNG，三发型×两体型共用行走，800ms；40采样时刻编码为38帧，解码回查40时刻RGB完全一致。

108个静态组合全部44px，1212次实际渲染没有裁切、半透明边缘或头部件变换分离；108组合的8个关键姿势均有8张不同栅格图。不同发眼组合不改变纯衣输出。192种材质组合的五官/保护区未变；32项真实界面回调检查通过。实际浏览器已验证眼/发/体独立选择、第五姿势保持、染色、分层、纯衣骨骼、播放暂停，控制台无warning/error。

仍需区分功能与美术：这批是候选，不代表用户已接受最终风格。共用脸底的嘴色比旧版偏红，部分衣领深边和刚性裙的动作仍有精修空间。

## 当前范围

本批新增模块只完成正面。侧背发脸、独立表情/眨眼、自由鼻嘴编辑、任意身体滑杆、新模块与饰品武器全组合尚未验收。裙摆是刚性片，无布料物理；浅藕裙原有部分姿势的裙腿局部接触限制未在本次解决。没有把整体缩放或整张动画帧伪装成可组合部件。
